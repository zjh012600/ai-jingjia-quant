# AI竞价量化系统

基于 A 股集合竞价公开行情数据的数据整理与数值统计工具。

## 功能介绍

- 每日采集集合竞价阶段的公开行情数据，进行客观整理与数值统计
- 展示竞价涨跌分布、量比、竞价形态等统计指标
- 提供多个数据分类视角：主力评分、黄金、万两、主板尾盘、创业尾盘、转债尾盘
- 支持查看历史数据与回测统计页面

本工具仅对已发生的公开数据做整理与呈现，不做任何前瞻性输出。

## 合规声明

1. 本工具仅对公开行情数据进行客观整理与数值统计，不提供证券投资咨询服务。
2. 所有展示内容均为历史数据的统计呈现，不含对未来走势的预测、判断或推荐，不构成投资建议。
3. 不提供个股推荐、买卖点位提示、跟单或带单服务，不承诺任何收益。
