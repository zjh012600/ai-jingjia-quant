## 功能介绍

- 每日采集集合竞价阶段的公开行情数据，进行客观整理与数值统计
- 展示竞价涨跌分布、量比、竞价形态等统计指标
- 提供多个数据分类视角：主力评分、黄金、万两、主板尾盘、创业尾盘、转债尾盘
- 支持查看历史数据与回测统计页面

本工具仅对已发生的公开数据做整理与呈现，不做任何前瞻性输出。
